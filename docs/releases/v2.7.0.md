# VPSentinel v2.7.0

发布日期：2026-10-16。适用于运行境外 Linux VPS、需要统一订阅、节点监控和受控自愈的自建用户。

## 本次更新

### EdgeTunnel 实测优选

- 接入最多三个 HTTPS 文本候选源，支持纯 IPv4 和 `IP:443#备注`；保留来源、运营商分类，去重并过滤非 Cloudflare 公网 IPv4、宣传行和不支持的端口。
- 按来源及分类轮换候选，每轮最多 24 个、最多 4 个并发，每个地址检测两次；支持来源缓存、失败回退及定时刷新。
- 经实际 VLESS-over-WebSocket 隧道验证目标 HTTPS 证书并下载 64 KiB；可选 Cloudflare 或 Wikimedia，减少单一测试目标不可达造成的误判。
- 仅将检测通过、端点指纹匹配且未超过 6 小时的结果下发到订阅；失败轮次保留有效旧池。
- 增加专用探测设备的登记、任务领取、结果上报与撤销；设备令牌与管理凭据隔离。
- 保留刷新接口的 `clean_ips` 快照字段，并恢复带协议、路径的域名输入兼容性。

### 控制台体验

- 手机端底部五项导航、触控尺寸、表单、订阅类型横向切换及可滚动弹窗。
- 模块和订阅格式写入地址，刷新与浏览器前进、后退恢复对应页面；兼容旧 `?tab=...` 链接。
- 示例：`/sentinel#/rules/singbox`、`/sentinel#/transits`。自定义安全入口时保留实际入口路径。

### 国内运营商延迟探测

- 修复受限服务账号无法执行 ICMP 却显示为 100% 丢包的问题。
- 安装独立、无文件 capabilities 的 ping 副本；仅在系统 ICMP 组策略被禁用时为服务组启用普通 ICMP socket，保留空 capability 集合与 `NoNewPrivileges`。
- 明确区分权限不足、缺少工具、进程超时和目标不回应；无有效样本不再生成虚假的国内平均延迟和评级。
- 修复表格行列被 HTML 清理破坏的问题，改用 DOM 单元格与文本写入。

### 安全与可靠性

- 汇总此前未发布的管理、订阅、Mesh 监控和证书同步权限隔离、敏感文件保护、外连限制、依赖锁定及受限本地辅助服务等整改。
- 读取实际 x-ui WAL 数据库时保留受限服务权限，修复概览字段和订阅状态兼容问题。
- 新增按标签发布的流程；同一提交的安全与回归检查通过后才创建 GitHub Release。

## 升级说明

1. 对照此 Release 对应的提交核验源码版本；备份运行配置、证书、OCI 凭据及服务单元。参见 [安全整改与迁移说明](https://github.com/imprprpr/vpsentinel/blob/v2.7.0/docs/SECURITY-REMEDIATION-2026-10-13.md)。
2. 已部署实例按现有部署方式更新。后端有改动时仅重启 VPSentinel 管理服务；页面单独更新时刷新浏览器。避免直接重跑涉及防火墙和其他服务的安装流程。
3. 已有受限服务如不能执行 ICMP，可由管理员在核对脚本后运行 `sudo bash /opt/vpsentinel/scripts/configure-ping.sh`。已有且不包含服务组的有效 ICMP 组策略会保留，需由管理员决定如何配置。
4. 使用 Wikimedia 检测时，探测设备也需更新到同版本；更改端点或检测目标后重新检测并更新客户端订阅。
5. 管理员、订阅、Mesh 和证书同步凭据各司其职；按迁移说明核对旧的集成配置。

## 验证与边界

- 仓库 CI 覆盖 Python 3.10、3.12、3.14，以及前端安全检查、依赖审计；本次发布流程以同一提交检查成功为前提。
- 已有部署环境中实际完成过两个 EDT 端点的 HTTPS 下载、三种订阅格式的 EDT 节点下发，以及八个 ICMP 目标的重新探测；这些结果仅代表当时环境，不保证其他网络的性能。
- 服务器侧 EDT 与 ICMP 检测不代表国内用户实际体验。真实三网优选需要对应运营商网络上的可信探测设备；第三方列表中的线路标签不是本地实测证明。
- 当前 EDT 检测范围为 IPv4、TLS 443、标准 VLESS TCP-over-WebSocket。短下载速度不是线路极限带宽，自动换 IP 也需要完整凭据、适用云资源与触发证据。

## 回退

使用升级前保存的源码与服务单元恢复管理服务。保留运行配置、证书和凭据的备份；涉及配置格式、凭据或系统策略的变更，应按实际改动核对恢复，避免直接覆盖现有状态。无需为了回退管理界面而重启代理核心。
